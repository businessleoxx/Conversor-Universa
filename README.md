README do Conversor Universal: programa Java de console para praticar classes, heranca, sobrescrita de metodos e colecoes. Converte Celsius para Fahrenheit e joules para calorias. Requer JDK 8+. Execute javac Conversor.java ConversorEnergetico.java ConversorTermico.java Principal.java e depois java Principal. O menu registra resultados somente durante a execucao e permite listar ou remover conversoes.
