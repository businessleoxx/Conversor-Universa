# Conversor Universal

Aplicação de console em Java para praticar classes, herança, sobrescrita de métodos e coleções. O menu registra conversões em memória e permite listar ou remover resultados.

## Conversões implementadas

- Temperatura: Celsius para Fahrenheit
- Energia: joules para calorias

As opções do menu usam essas unidades como origem e destino fixos. As classes também contêm outras regras de conversão como exercícios de orientação a objetos.

## Requisitos

- JDK 8 ou superior

## Como executar

Na pasta que contém os arquivos Java, compile e inicie o programa:

javac Conversor.java ConversorEnergetico.java ConversorTermico.java Principal.java
java Principal

No menu, escolha uma conversão, liste os resultados registrados ou remova um item pelo índice. Os dados são mantidos apenas enquanto o programa estiver aberto.
